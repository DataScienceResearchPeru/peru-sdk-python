# Reglas del repositorio

- Usar subdirectorios únicos de `/var/tmp` para temporales, scripts de trabajo y resultados intermedios.
- No añadir firmas, marcas ni atribuciones de herramientas en código, documentación, commits o descripciones.
- Respetar la identidad Git configurada.
- No incorporar código, plantillas ni suites de proyectos de referencia.
- Editar contratos antes de regenerar modelos; no modificar los modelos generados manualmente.
- Mantener Go y Python nativos, con dependencias pocas y justificadas.
- No presentar datos simulados como compatibilidad comprobada con instituciones.
- No enviar consultas reales ni usar secretos en tests ordinarios.
